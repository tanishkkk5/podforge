# Review standard — AI drafts, a human approves

**Purpose:** AI makes content cheap to produce. If unchecked content reaches guests, creators or listeners,
people stop trusting everything we send. Own your output: review it before anyone else has to.

**Rules:**
1. Every guest kit and creator kit starts as **Draft**. Its public link shows "being prepared" until a
   person marks it **Approved** in Podforge (name + date are recorded).
2. Before approving, check: names spelled right · Profit Streams® correct · captions read naturally ·
   no invented facts · video links open.
3. Regenerating a kit puts it back to Draft.
4. Emails are always created as drafts, never sent automatically.
5. Code and knowledge changes pass the automatic check before going live (see `CONTRIBUTING.md`).

**Enforcement:** the approval gate is built into the guest kit and creator kit pages; the GitHub check runs on every push.
