# Daily and weekly report format

**Rule:** report the actual current state — never overstate progress.

**Daily (around 5 PM IST)**
```
Daily Update – [Day, Month DD, YYYY]

What I worked on / completed yesterday:
-

What I plan to work on / complete today:
-

Where I am blocked:
-
```

**Weekly (Fridays — replaces that day's daily)**
```
Agreements
-
Accomplishments
-
Near Term Plans (1-3 weeks)
-
Longer Term and/or Ongoing Activities (1-3 months)
-
Comments / Questions / Concerns
-
Applied Frameworks Open Action Items
-
```
