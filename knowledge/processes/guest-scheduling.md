# Scheduling a recording

1. **Check the host's real calendar yourself** first.
2. **Book using the guest's own scheduling link** (Calendly etc.) if they have one.
   Don't email back and forth proposing times — it puts extra work on the guest (Luke's explicit feedback).
3. Create the Riverside studio session and put its link in the invite.
4. The **host should be the invite organizer**. If you book on their behalf, you need calendar delegation;
   otherwise you show as organizer — flag it to the host.
5. Optionally create a Podforge session (`/admin`) so the guest gets a confirmation page.
