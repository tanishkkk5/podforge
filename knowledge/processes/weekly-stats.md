# Weekly stats check-in (every Monday, ~2 minutes)

1. Production Assistant shows **"Weekly stats check-in"** until this week is entered. Open **Weekly Stats**.
2. **Spotify:** creators.spotify.com → the show → Overview → copy **Followers** and **Plays (last 7 days)**;
   Episodes tab → latest episode's plays.
3. **Apple:** podcastsconnect.apple.com → Analytics → the show → copy **Followers** and **Plays**; latest episode's plays.
4. Save. Podforge shows followers gained since last week and 12-week trends.
5. Use these numbers in the Friday weekly report.
